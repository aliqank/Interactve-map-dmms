# Функционал множественной отправки точек

## Описание

Новый компонент `MultiPointSendingComponent` позволяет выбирать несколько точек на карте, визуально соединять их линиями и отправлять координаты в API с интервалом 1 секунда.

## Возможности

### Основные функции:
- **Выбор точек**: Кликайте по карте для добавления точек
- **Визуальное соединение**: Точки автоматически соединяются пунктирной линией
- **Отправка с интервалом**: Точки отправляются в API с интервалом 1 секунда
- **Статус отправки**: Каждая точка показывает свой статус (ожидание, отправка, успех, ошибка)
- **Управление**: Кнопки для начала/остановки отправки и очистки точек

### Визуальные элементы:
- **Маркеры точек**: Синие кружки для выбранных точек
- **Статус маркеров**: 
  - Синий - ожидание
  - Зеленый - успешно отправлено
  - Красный - ошибка отправки
- **Пунктирная линия**: Соединяет точки в порядке выбора
- **Информационные попапы**: Показывают координаты и статус каждой точки

## Использование

### 1. Активация режима
- Нажмите кнопку "Multi-Point Sending" в боковой панели
- Или используйте горячую клавишу `T`

### 2. Выбор точек
- Кликайте по карте для добавления точек
- Точки автоматически нумеруются и соединяются линией
- В правом верхнем углу появится панель управления

### 3. Отправка точек
- Нажмите "Начать отправку" для старта процесса
- Точки будут отправляться по одной с интервалом 1 секунда
- Прогресс отображается в панели управления
- Можно остановить отправку в любой момент

### 4. Управление
- **Остановить**: Прерывает процесс отправки
- **Очистить все**: Удаляет все точки с карты
- **Закрыть**: Скрывает панель управления

## Технические детали

### Компоненты:
- `MultiPointSendingComponent`: Основной компонент
- `Point`: Интерфейс для хранения данных точки
- Leaflet маркеры и полилинии для визуализации

### API интеграция:
- Использует тот же API endpoint, что и обычная отправка
- Таймаут 5 секунд на каждую точку
- Обработка ошибок с визуальной индикацией

### Состояния точек:
```typescript
interface Point {
  lat: number;
  lng: number;
  marker: L.Marker;
  popup: L.Popup;
  sent: boolean;
  error: boolean;
}
```

## Горячие клавиши

- `T` - Активировать режим множественной отправки точек
- `ESC` - Закрыть активный режим

## Стилизация

Компонент использует современный дизайн с:
- Адаптивной панелью управления
- Анимациями и переходами
- Цветовой индикацией статусов
- Адаптивностью для мобильных устройств

## Интеграция с существующей системой

- Интегрирован в боковую панель инструментов
- Использует общие настройки API
- Совместим с существующими компонентами
- Поддерживает те же настройки безопасности

## Пример использования

1. Откройте карту
2. Нажмите `T` или выберите "Multi-Point Sending" в панели
3. Кликните по карте в нескольких местах
4. Нажмите "Начать отправку"
5. Наблюдайте за процессом отправки точек
6. Используйте "Очистить все" для удаления точек
